PORTAFOLIO - PUBLICACION EN GITHUB PAGES

1. En GitHub crea un repositorio PUBLICO llamado <nombre-de-organizacion>.github.io para una organizacion, o diego69523-tech.github.io para tu usuario.
2. Sube el CONTENIDO de esta carpeta (index.html, styles.css, app.js e imagenes/), no la carpeta contenedora ni un ZIP.
3. En Settings > Pages selecciona Deploy from a branch, main y /(root). Guarda.
4. Abre el enlace de GitHub Pages cuando GitHub confirme la publicacion.
